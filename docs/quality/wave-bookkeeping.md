# Wave Bookkeeping

## Regra

Cada wave só pode ser marcada como concluída quando houver evidência executável e documentação correspondente.

## Evidência mínima

- link para workflow ou comando local;
- resultado de teste ou lint;
- artefato gerado quando aplicável;
- atualização de status no roadmap.

## Fechamento

1. Validar tarefas da wave.
2. Registrar evidências.
3. Atualizar `ROADMAP-QUALITY-ENFORCEMENT-WAVES.md`.
4. Atualizar `ISSUES-QUALITY-ENFORCEMENT-WAVES.md`.
5. Atualizar `PENDING-ACTIVITIES.md` quando necessário.
