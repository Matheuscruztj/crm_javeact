# Dashboard Operacional de Qualidade

## Indicadores mínimos

- tempo médio dos gates locais;
- taxa de falha por check;
- findings de segurança por severidade;
- cobertura backend e frontend;
- número de exceções ativas;
- idade média das exceções;
- status do nightly.

## Fontes

- artifacts do GitHub Actions;
- reports do Gradle;
- reports de cobertura;
- SBOM;
- relatórios de segurança.

## Uso

- acompanhar regressão;
- identificar checks caros;
- decidir promoção de advisory para blocking;
- revisar tendências mensais.
