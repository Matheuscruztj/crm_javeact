# SLA de Remediação

## Prazos

| Severidade | SLA alvo |
| --- | --- |
| `CRITICAL` | 24 horas |
| `HIGH` | 72 horas |
| `MEDIUM` | 14 dias |
| `LOW` | 30 dias |

## Observações

- O SLA conta a partir da confirmação do finding.
- Findings sem owner explícito devem ser atribuídos no mesmo dia útil.
- Findings recorrentes devem ser tratados como dívida estrutural, não como exceção repetida.
